# Lexora - Projet PHP final

## Installation

1. Place le dossier `lexora_database_complete` dans `xampp/htdocs/lexora/PFA/`.
2. Démarre Apache et MySQL depuis le panneau XAMPP.
3. Ouvre dans ton navigateur :
   - `http://localhost/lexora/PFA/lexora_database_complete/`

## Configuration

Le fichier de configuration se trouve dans `config/config.php`.

- `base_url` doit être : `/lexora/PFA/lexora_database_complete`
- `assets_url` doit être : `/lexora/PFA/lexora_database_complete/assets`

## Notes

- Le projet utilise PHP et MySQL.
- Assure-toi que la base de données `lexora` existe et que les tables nécessaires sont créées.
- Si la base de données n'est pas en place, le site risque de renvoyer une erreur de connexion.

## Résultat

Tu devrais pouvoir voir l'application dans ton navigateur avec les styles CSS et les scripts JavaScript chargés correctement.
